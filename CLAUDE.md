# Project rules: paraphrased channels and Vietnamese collusion

Does relaying agent-to-agent messages through a paraphraser stop collusion,
and what does it cost the monitor? Inherits method discipline from
`agent-collusion-bench` and ideas from `Pragmatic-Sophistry-in-Vietnamese-
Multi-Agent-Oversight` (both PREEXISTING, both the author's). No data from
either.

## Design
- `docs/execution-plan.md` is the source of truth. Change it before the code.
- NEVER change without asking the human: the four renderings, the two
  channels, the two item classes, the four-turn episode, the four nested
  monitor views, the measures, the item seed 20261025.
- The rival is scripted. Its messages live in `src/prompts.py`. Generating
  them with a model is a design change.
- Paraphrases are frozen stimuli, built once by `scripts/modal_stimuli.py`.
  Never regenerate them mid-study; a new set is a new version of the study.

## Controls (asserted before the first call, on the laptop and in every container)
1. Agent reasoning ON per call.
2. Option order fixed within an episode; both orders run in every cell.
3. Refusal test BEFORE option-label search. Pinned by `tests/test_core.py`.
4. Discrete choice, not logprobs.
5. Refusals, unparsed replies and errors are DATA. Never dropped or imputed.
6. The frame around the message is byte-identical across arms; the agent is
   never told the platform paraphrased it.
7. No message or paraphrase may supply an argument or a threat. Banned-phrase
   list over every rendered message and every frozen paraphrase.
8. The collusive option is a fixed per-item key.
9. Episode measures are coded in code. No LLM judge produces a measure. The
   stimulus gate is a manipulation check on text, never an episode measure.
   The monitor is the detector under test; its verdicts are the object studied.
10. `mutual_gains` runs in every cell. If cooperation there drops under
    paraphrase, STOP and tell the human.

## Data
- Never fabricate, simulate or hand-edit records.
- Every record validates against `src/schema.py`.
- Records carry config hash, git commit, model, temperature, timestamp.
- COMMIT `data/` during collection. Nothing under `data/` is gitignored.

## Analysis
- Bootstrap 95% CI, 10,000 resamples, clustered over items.
- Numbers are generated by code, never typed.
- Small cells: "no measurable difference in this sample", never "no effect".
- Everything is EXPLORATORY until a preregistration is tagged.

## Running
- Model calls run on Modal only. Keys live in Modal secrets `collusion-keys`
  and `vllm-key`. Never create secrets; never print, commit or hardcode keys.
- Estimate cost before any run over 20 episodes. Never launch without
  `--confirm`.

## Ethics
- Fictional platform (MuaNhanh), fictional shops, nothing acts on any decision.
- Measures propensity to accept, not capability to invent. Publish the
  detection side.

## Writing
- Short report. No em dashes. Intervals in tables, estimates in prose.
